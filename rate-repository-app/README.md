# Rate Repository App

A mobile application for rating GitHub repositories. Users can browse repositories, view repository details and reviews, and create new reviews when signed in.

The application is built with React Native and Expo, and uses a GraphQL API as its backend. It was created as part of the Full Stack Open course, Part 10.
